## مجوز

این نرم‌افزار تحت **مجوز آپاچی، نسخهٔ ۲٫۰** (Apache License 2.0) منتشر
می‌شود. متن کامل و الزام‌آور مجوز در فایل [LICENSE](../../LICENSE) در
ریشهٔ مخزن است؛ این صفحه فقط خلاصهٔ فارسی است و در هیچ تعارضی جایگزین
متن اصلی نمی‌شود.

خلاصهٔ عملی مجوز آپاچه ۲٫۰:

- **استفاده:** می‌توانید کد را برای هر منظوری — شخصی یا تجاری —
  اجرا، مطالعه و تغییر بدهید.
- **توزیع:** می‌توانید نسخهٔ اصلی یا تغییریافته را بازتوزیع یا بفروشید،
  به شرط حفظ اعلان حق نشر و پیوست‌کردن متن مجوز.
- **پتنت:** مشارکت‌کنندگان به کاربران مجوز پتنتِ لازم برای استفاده از
  آن مشارکت را می‌دهند؛ اگر از کاربر علیه مشارکت‌کننده دعوای پتنت
  بزنید، این مجوز برای همان مشارکت باطل می‌شود.
- **تغییرات:** تغییرات خودتان باید به‌روشنی علامت‌گذاری شوند.
- **بدون ضمانت:** نرم‌افزار «همین‌طور که هست» ارائه می‌شود؛ بدون هیچ
  ضمانتی، صریح یا ضمنی. نویسنده در برابر خسارات ناشی از استفاده
  مسئولیتی نمی‌پذیرد.

## وابستگی‌های اصلی

اجزای اصلی MeshSync و مجوزهایشان (فهرست کامل و الزام‌آورِ هر نسخه در
SBOM همان نسخه منتشر می‌شود):

| جزء | نقش | مجوز |
|---|---|---|
| زبان Go و کتابخانه استاندارد | ایجنت | BSD-3-Clause |
| `modernc.org/sqlite` | SQLite با Go خالص | BSD-3-Clause |
| `github.com/fsnotify/fsnotify` | نظارت بر تغییر فایل | BSD-3-Clause |
| `github.com/gorilla/websocket` | رویدادهای WebSocket | BSD-2-Clause |
| Next.js / React / Tailwind / shadcn | کنسول وب | MIT و مجوزهای سازگار |
| Flutter SDK | کلاینت موبایل | BSD-3-Clause |
| کتابخانه استاندارد C++ | موتور هش بومی | مجوز کامپایلر/زبان |

## علامت‌گذاری

عبارت «MeshSync» فقط برای اشاره به این پروژه و نسخه‌های رسمی آن استفاده
شود؛ forkها باید نام و هویت متمایزی داشته باشند تا با پروژهٔ اصلی
اشتباه نشوند.
